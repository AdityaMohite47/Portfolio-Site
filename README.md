# Portfolio — Aditya Mohite

Personal developer portfolio built with React + Vite.

## Live Site

[adityamohite.in](https://adityamohite.in)

## Stack

- **React** + **Vite**
- **react-icons** for brand and UI icons
- **Raleway** and **Space Mono** via Fontsource

## Sections

- **Hero** — introduction, current role, tech I work with
- **Projects** — Campus Canteen (with an in-browser replay of the order bot), KeepNotes, short.ly
- **Certificates** — Anthropic, Udemy and GitHub, each viewable full size with a verify link
- **More work** — every other public repository, filterable by area
- **Get in touch** — opens a Gmail draft addressed to me

## Deploy

- **GitHub Pages:** pushes to `main` build and deploy via `.github/workflows/deploy.yml`.
- **VPS (adityamohite.in):** `VPS_BUILD=true npm run build`, then copy `dist/` to the nginx web root.
